#### 기본 조작
    - 복사 : Cmd+C
    - 붙여넣기 : Cmd+V
    - 잘라내기 : Cmd+X
    - 실행취소 : Cmd+Z
    - 다시실행 : Cmd+Shift+Z
    - 전체 선택 : Cmd+A
    - 저장 : Cmd+S
    - 인쇄 : Cmd+P
    - 찾기 : Cmd+F
    - 스팟라이트 검색 : Cmd+Space

#### 창/앱 전환
    - 앱 전환 : Cmd+Tab
    - 같은 앱의 다른 창 전환 : Cmd+`
    - 현재 창/탭 닫기 : Cmd+W
    - 앱 완전 종료 : Cmd+Q
    - 창 최소화 : Cmd+M
    - 앱 숨기기 : Cmd+H
    - 강제 종료 창 열기 : Cmd+Option+Esc

#### Finder / 파일 관리
    - 새 Finder 창 : Cmd+N
    - 새 폴더 : Cmd+Shift+N
    - 휴지통으로 이동 : Cmd+Delete
    - 휴지통 비우기 : Cmd+Shift+Delete
    - 퀵룩(미리보기) : Space
    - 정보 가져오기 : Cmd+I
    - 상위 폴더 이동 / 열기 : Cmd+Up/Down
    - 숨김 파일 표시/숨기기 : Cmd+Shift+.

#### 화면 캡처
    - 전체 화면 캡처 : Cmd+Shift+3
    - 영역 지정 캡처 : Cmd+Shift+4
    - 특정 창 캡처 : Cmd+Shift+4 → Space
    - 캡처/녹화 옵션 패널 : Cmd+Shift+5

#### 텍스트 편집
    - 줄 처음/끝 이동 : Cmd+Left/Right
    - 문서 처음/끝 이동 : Cmd+Up/Down
    - 단어 단위 이동 : Option+Left/Right
    - 줄 전체 삭제 : Cmd+Backspace
    - 단어 단위 삭제 : Option+Backspace

#### Mission Control
    - Mission Control 열기 : Control+Up
    - 데스크톱(스페이스) 전환 : Control+Left/Right
    - 데스크톱 보기 : F11 / Fn+F11

#### 개발 관련
    - 터미널 새 탭 : Cmd+T
    - 터미널 화면 지우기 : Cmd+K
    - 에디터 커맨드 팔레트 : Cmd+Shift+P
    - 에디터 주석 처리 : Cmd+/
    - 에디터 다음 동일 항목 선택 : Cmd+D
